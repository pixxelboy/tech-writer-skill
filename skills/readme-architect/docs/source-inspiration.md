# Source Inspiration

README Architect is inspired by recognized open-source README best practices. These sources are references for reusable documentation patterns only. README Architect must not copy their source material or reproduce their templates verbatim.

> README Architect does not copy templates. It learns patterns, detects project context, and composes the most useful README for that repository.

## Best README Template

`othneildrew/Best-README-Template` is useful inspiration for:

- clear table of contents
- badges
- about section
- getting started
- usage
- roadmap
- contributing
- license
- contact / acknowledgements

README Architect adapts these as structural options, not as a fixed template.

## Awesome README

`matiassingers/awesome-readme` is useful inspiration for:

- visual polish
- strong examples
- demo-first storytelling
- screenshots
- personality
- scannable structure

README Architect uses these as quality signals: good READMEs are easy to scan, show rather than only tell, and have a voice appropriate to the project.

## README Best Practices

`jehna/readme-best-practices` is useful inspiration for:

- clarity
- installation
- usage examples
- contribution guidance
- maintenance signals
- project status

README Architect treats these as minimum open-source readiness checks.

## Top open-source projects

High-quality projects such as Next.js, Supabase, Cal.com, Payload CMS, Appwrite, LangChain, FastAPI, and Home Assistant are useful inspiration for:

- concise positioning
- badges
- quick start
- architecture diagrams
- demo links
- API examples
- clean section hierarchy
- contributor onboarding

The goal is not to mimic any one project. The goal is to infer why the README works and adapt that pattern to the current repository's evidence, audience, and project type.

## Anti-copying note

External sources are inspiration for patterns only. Do not copy their wording, section order, badges, examples, diagrams, or template text verbatim. Generated README content must come from the target repository's evidence map.
